transmissionbtm 隐私政策

发布时间：2026-08-28　·　运营者：陈锡金　·　联系邮箱：21801713@qq.com

引言
本应用（「transmissionbtm」，下称「本应用」）是一款基于开源 Transmission libtransmission 引擎的 BitTorrent 下载客户端。我们深知个人信息对您的重要性，并会竭尽全力保护您的个人信息安全可靠。本政策将帮助您了解本应用如何收集、使用、存储和保护您的信息，以及您享有的相关权利。

一、我们如何收集和使用信息

我们坚持「本地运行、最小收集」原则。 本应用不收集、不上传任何个人信息。

信息来源是否收集详细说明
账号 / 身份信息❌ 不收集无注册、无登录、无账号体系
相机 / 麦克风 / 相册 / 定位 / 通讯录 / 短信❌ 不收集不声明、不申请、不使用相关权限
个人文件与内容⚠️ 仅本地您添加的种子、磁力链与下载文件仅存储在您指定的本地目录，不出设备
网络状态⚠️ 仅本地用读取当前网络类型与 WiFi SSID，用于「仅 WiFi 下载 / SSID 白名单」等本地网络策略判断，不对外传输
浏览 / 轨迹 / 设备指纹❌ 不收集无统计 SDK、无埋点、无设备唯一标识上报
广告❌ 不带广告无广告 SDK 与第三方内容加载

说明：BitTorrent 传输过程中的元信息（如 tracker 地址、对等节点）仅用于 P2P 握手与数据交换，是您发起下载所必需的技术行为，并非我们主动收集的信息。

二、权限使用说明

为提供下载功能，本应用在您首次使用时可能需要以下系统权限，均仅用于本应用核心功能：

  1. 网络访问（INTERNET）：BitTorrent 对等传输必需的联网通信。
  2. 后台运行（KEEP_BACKGROUND_RUNNING）：切换到后台后继续完成下载。
  3. 网络状态信息（GET_NETWORK_INFO）：检测 WiFi／移动数据，避免在移动数据下自动下载。
  4. WiFi 信息（GET_WIFI_INFO）：读取当前 WiFi SSID 以实现「仅白名单 WiFi 传输」，该信息仅在设备本地处理。

以上权限所涉数据均只在您的设备上本地处理，不会上传至任何服务器。

三、信息的存储

  • 所有下载内容与配置均存储于您设备本地的应用沙箱或您指定的目录。
  • 我们不设服务器、不存储您的任何数据副本。

四、与第三方的共享

本应用不与任何第三方共享您的个人信息。BitTorrent 对等传输是点对点的，直接发生在您的设备与所连节点之间，不经过我方服务器。

五、您享有的权利

由于本应用不收集您的个人信息，您通常无需行使查阅、更正、删除等权利。若您对个人信息保护有任何疑问、意见或建议，可通过下方联系方式与我们联系，我们将在 15 个工作日内回复。

六、未成年人保护

本应用为通用下载工具，不面向特定年龄群体收集个人信息。若您为未成年人，请在监护人指导下使用。

七、政策更新

我们可能适时修订本政策，修订后的政策会在此页面公布。重大变更将显著提示。
